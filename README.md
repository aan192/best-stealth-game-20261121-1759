# Trash Panda Midnight Gallery

An original top-down 2D stealth game where a sneaky raccoon burglar infiltrates a high-security museum at night. Dodge patrolling guards with yellow vision cones, slip behind walls and crates, collect 3 golden artifacts per gallery, and escape to the green exit across 3 challenging levels!

- **Controls**: WASD or Arrow Keys to move, `P` to pause, `M` to mute audio, `R` to restart.
- **Mechanics**: Line-of-sight guard cones, dynamic detection meter, artifact collection, timer, lives system, and WebAudio sound effects.
